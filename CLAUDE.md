# Choices Pregnancy Care Center — site guide

Static site, no build step. 36 hand-written HTML pages at repo root + `styles.css` + `script.js`. Also a PWA (`sw.js`, `manifest.json`) and a Capacitor iOS app (`ios/`, `www/`).

## Rules for every edit

1. **Bilingual text — the big trap.** User-visible text is stored twice: inline in the HTML *and* in `data-en`/`data-es` attributes. The language toggle (script.js ~line 398) overwrites inline text from those attributes. When changing any visible copy:
   - Update the inline text AND `data-en` (keep them identical).
   - Update `data-es` with the Spanish translation.
   - Form placeholders use `data-en-placeholder`/`data-es-placeholder`.
   - An element with no `data-en` attribute is safe to edit directly.

2. **Repo root is the source of truth.** Never hand-edit files in `www/` — it's the Capacitor webDir, regenerated by `npm run sync` (copies root HTML/CSS/JS/icons/images into `www/`). Run the sync after root edits when an iOS build is planned.

3. **Shared chrome is duplicated on every page.** The navbar, crisis banner, and footer are copy-pasted into all root-level HTML pages. A change to any of them must be applied to every `*.html` at root (grep to find all occurrences; verify the count matches the page count).

4. **`partners/` is a separate donor-facing mini-site** with its own copies of nav/footer. It is NOT synced to `www/` and is only affected if a change is meant for it.

5. **Service worker:** network-first, so content edits show up without cache tricks. Only bump `CACHE_NAME` in `sw.js` when changing which files are precached or when changing `offline.html`.

## Workflow for client change requests

- One branch per batch of changes; keep `main` deployable.
- Preview locally with `npm run serve` (http://localhost:8080), check the page in both English and Spanish (toggle in navbar) and at mobile width.
- Before committing, `git diff` and confirm only intended files changed.

## Commands

- `npm run serve` — local preview server
- `npm run sync` — copy root web files → `www/` for the iOS app
